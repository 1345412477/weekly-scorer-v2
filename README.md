# 周报评分系统 v2

基于 AI 的智能周报评估平台，通过自动化评分机制提升团队周报质量，为管理者提供数据化的团队工作表现洞察。

### 用户角色说明

| 角色   | 登录方式      | 功能权限                       |
| ---- | --------- | -------------------------- |
| 管理员  | 需要密码验证登录  | 仪表盘、周报列表、评分配置、模板管理、部门/人员管理 |
| 普通用户 | 无需密码，直接进入 | 提交周报、查看排行榜                 |

## ✨ 核心功能

- **管理配置**：评分维度、权重、等级阈值、AI Prompt、模板管理
- **模板管理**：周报模板CRUD、默认模板设置
- **周报管理**：文件上传（Excel/Word/PDF）、在线编辑、草稿保存、提交评分
- **AI 评分**：多维度自动评分，支持 DeepSeek/豆包/MiMo API，规则降级兜底
- **排行榜**：评分排名、等级分布、时间趋势、多维度筛选
- **部门/人员管理**：部门信息管理、人员信息管理
- **数据监控**：数据状态概览、数据库备份、AI服务状态检测

## 🛠️ 技术栈

| 层  | 技术                                           |
| -- | -------------------------------------------- |
| 前端 | Vue 3 + PrimeVue 4 (Aura) + ECharts 5        |
| 后端 | FastAPI + SQLAlchemy (async) + SQLite        |
| AI | DeepSeek API / 豆包 API / MiMo API (OpenAI 兼容) |

## 🚀 快速启动

### 后端

```bash
cd backend
python -m venv venv
venv/Scripts/activate   # Windows
pip install -r requirements.txt
cp .env.example .env     # 填入 AI API Key
python -m uvicorn app.main:app --host 0.0.0.0 --port 8002 --reload
```

### 前端

```bash
cd frontend
npm install
npm run dev
```

访问 <http://localhost:3001>

## 📊 默认配置

### 默认评分维度

| 维度名称   | 满分 | 考核内容         |
| ------ | -- | ------------ |
| 工作反馈深度 | 14 | 问题发现+分析+解决方案 |
| 进度节点明确 | 13 | 项目是否有明确进度/节点 |
| 计划可行性  | 10 | 下周计划是否具体可执行  |
| 工作连续性  | 13 | 是否承接上周计划且有闭环 |

### 默认等级阈值

| 等级 | 分数阈值 |
| -- | ---- |
| 优  | ≥45  |
| 良  | ≥38  |
| 一般 | ≥33  |
| 差  | <28  |

## 📝 开发说明

### API 文档

后端启动后，可以访问 `http://localhost:8002/docs` 查看 Swagger API 文档。

### 评分流程

1. 用户提交周报（文件上传）
2. 系统自动识别周报时间并分类
3. 调用 AI 服务进行评分，AI 服务不可用时提示原因
4. 保存评分结果并更新周报状态

### 环境变量配置

在 `backend/.env` 文件中配置：

- AI API Key（DeepSeek/豆包/MiMo）
- 其他可选配置项

## 🔧 后期优化策略

### 用户权限分离

#### 管理员端

- **首页**：需要账号密码登录，拥有完整管理权限
- **仪表盘**：查看本周未提交人员、等级分布、差评人员、本周平均分
- **周报列表**：查看所有提交的周报，支持筛选和详情查看，管理所有用户提交的周报
- **配置管理**：评分维度、权重、等级阈值、AI Prompt、模板等系统配置

#### 普通用户端

- **用户主页**：整合提交周报和排行榜功能，用户可在同一页面完成周报提交并查看个人评分排名
- **提交功能**：对周报提交追加限制，每周周报只能提交一次，需要管理员后台删除才能再次提交，并且严禁提前提交
- **补交扣分**：对补交周报的行为直接扣5分无需登录，直接进入用户主页
- **查看排行榜**：查看个人评分和排名

### 页面整合

将提交周报和排行榜功能整合为单一用户主页面，用户登录后可直接：

1. 提交本周周报
2. 查看个人评分及排行榜信息

### 仪表盘重构

管理员仪表盘重构成以下核心指标：

1. **本周未提交人员**：列出本周尚未提交周报的成员
2. **等级分布**：以图表形式展示各等级人数占比
3. **等级为差人员**：列出评分等级为"差"的成员及详情
4. **本周平均分**：展示本周周报的平均得分

### UI/UX 优化

- **视觉风格**：采用更现代化的设计，优化配色方案和排版
- **交互体验**：简化操作流程，减少点击次数
- **响应式设计**：适配桌面端和移动端设备
- **数据可视化**：优化图表展示，信息层次更清晰
- **加载性能**：优化首屏加载速度，减少等待时间

## 🎯 项目目标

- **效率提升**：自动评分替代人工评审，节省 80% 的周报审核时间
- **质量提升**：通过多维度评分引导员工产出高质量周报
- **数据洞察**：提供周报质量趋势分析、团队排行榜等数据可视化
- **灵活配置**：支持自定义评分维度、权重和等级标准
- **降级兜底**：AI 服务不可用时自动切换为规则评分
